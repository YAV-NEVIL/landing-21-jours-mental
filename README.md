# landing-21-jours-mental
Landing Page Officielle - 21 Jours pour Reprogrammer son Mental (Dani Mariotte)

Landing page cinématographique haute fidélité construite avec React 19, Vite, Tailwind CSS et GSAP.

## Fonctionnalités
- Showcase 3D du livre avec zoom ultra-haute définition
- Lecteur audio interactif de l'extrait du Jour 1
- Micro-interfaces réactives : Mélangeur diagnostique, Télémétrie live, Planificateur de protocole
- Grille tarifaire et modale de commande Chariow intégrée

## Installation & Démarrage local
```bash
npm install
npm run dev
```
